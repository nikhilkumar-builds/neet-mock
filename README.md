# NEET Mock Test

Teacher panel (/admin.html) and student panel (/student.html), built with HTML, CSS, JS, Node.js (Express) and MongoDB.

Local run: copy `.env.example` to `.env`, fill it in, then `npm install` and `npm run dev` and open http://localhost:3000
Deploy: push to GitHub, import the repo in Vercel, add the 4 variables from `.env.example`.
